# Steerion Labs

### Engineering trustworthy AI systems for real-world work.

Steerion Labs is an independent AI engineering and R&D initiative focused on **agentic systems, decision intelligence, automation, and developer infrastructure**.

We build around a simple principle:

> **AI can be capable without owning authority.**

Our work explores how intelligent systems can plan, build, review, and automate meaningful work while keeping evidence, permissions, protected actions, and human decisions explicit.

## What we care about

- **Agentic AI** — practical autonomous and semi-autonomous workflows
- **AI safety by architecture** — bounded authority, explicit scopes, verifiable evidence
- **Decision intelligence** — clearer decisions from evidence, not opaque automation
- **Developer infrastructure** — tools that make AI-assisted engineering more reliable
- **Human control** — protected actions stay behind explicit authorization boundaries

## Featured open-source project

### [Bounded Agent Runtime (BAR)](https://github.com/steerion-labs/bounded-agent-runtime)

**Give coding agents freedom to work. Keep authority out of the model.**

BAR is a model-agnostic security runtime for autonomous coding agents. It can orchestrate tools such as **Codex, Claude Code, OpenCode, containers, and custom agents** while a deterministic controller owns the boundaries around:

- task scope and allowed actions
- candidate identity and evidence
- verification
- independent review
- budgets and retries
- protected-action authorization
- Human Gates

```text
Task → Builder → Verified Candidate → Reviewer → Human Gate
```

BAR is designed for teams building autonomous coding loops, multi-agent engineering workflows, or security-conscious automation where the model itself should not become the final authorization boundary.

**Apache-2.0 · Open source · Model agnostic**
